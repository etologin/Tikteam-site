Kaspi on iPhone

Connect Kaspi Gold top-up notifications to TikDonate.

Get a key or QR code in your account

Setup

  1. On your computer, open TikDonate → Connections → Connect Kaspi from iPhone.
  2. Select iPhone QR code and link. Scan the QR code or open the link in Safari within five minutes.
  3. Select Copy code and open Shortcuts. Paste the code when prompted. Enable the Kaspi automation if your iPhone asks.

If you already copied your key, you can open the shortcut directly.

Open iCloud shortcut

The key stays valid until you unlink it. Each account has one iPhone connection. To switch phones, select Unlink iPhone in TikDonate.
