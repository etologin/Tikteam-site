# TikTeam brand kit

Logo: the "gift" mark — a T formed by a gift box ribbon, with a bow on top — in the Neon gradient.

## Files

| File | Use |
|---|---|
| `tikteam-mark.svg` | Master mark. Any size from 32 px up. |
| `tikteam-mark-small.svg` | Simplified mark without the bow, for 16–24 px (favicons, tray icons). |
| `tikteam-mark-square.svg` | Full-bleed square for iOS and app stores, which round the corners themselves. |
| `tikteam-logo-dark-bg.svg` | Horizontal logo for dark backgrounds. |
| `tikteam-logo-light-bg.svg` | Horizontal logo for light backgrounds. |
| `tikteam.ico` | Windows icon, 16–256 px. |
| `png/` | Ready PNG exports, including the 1200×630 link preview. |

The wordmark in both horizontal logos is already converted to outlines, so it does not depend on an installed font.

## Colors

| Name | HEX |
|---|---|
| Neon cyan | `#2BD9FE` |
| Neon violet | `#7B5CFF` |
| Neon pink | `#FF3D8B` |
| Background | `#06070A` |
| Text on dark | `#F2F4F8` |
| Text on light | `#0B0C10` |

Gradient: cyan → violet (55%) → pink, diagonal top-left to bottom-right in the mark, left to right in text.

## Typography

- Headings and wordmark: **Unbounded** Bold, letter spacing −2%.
- Body text: **Manrope**.

Both are free fonts under the SIL Open Font License.

## Rules

- Keep clear space around the mark of at least a quarter of its width.
- Do not recolour, stretch, rotate or add shadows to the mark.
- Do not use TikTok's logo, note symbol or its cyan-and-red offset effect next to the TikTeam logo.
